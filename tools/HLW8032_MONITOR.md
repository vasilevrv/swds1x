# Диагностика HLW8032

Полностью отключить 230 В. Питать плату/измеритель отдельно от подходящего
изолированного низковольтного источника. USB-UART RX подключить к TX
HLW8032 (линия PC3/C3), GND к GND. TX, VCC, RTS, DTR адаптера не подключать.
Проверить совместимость логических уровней. Перед подачей 230 В полностью
отсоединить USB-UART. Прямое подключение ноутбука к плате под сетью недопустимо.

```sh
python3 -m venv /tmp/hlw-monitor-venv
/tmp/hlw-monitor-venv/bin/python -m pip install pyserial
/tmp/hlw-monitor-venv/bin/python smart_plug/tools/hlw8032_monitor.py \
  --port /dev/cu.wchusbserial10 --seconds 10 --raw /tmp/hlw_capture_01.bin \
  | tee /tmp/hlw_decode_01.jsonl
```

Скрипт настраивает 4800 8E1, сохраняет поток без изменений и ищет
24-байтовые кадры независимо от границ USB-пакетов. Проверяет заголовок
и сумму байтов 2…22 modulo 256. Показывает HEX, status, update, все
регистры, PF REG, перенос счётчика и номинальные V/A/W/VA/power factor.
По умолчанию коэффициенты как в board-файле: Kv=1.995, Ki=1.0.
Проверка суммы не проверяет UART parity: ОС/USB-UART может не передавать
ошибки чётности в pyserial; это не замена анализатору логических сигналов.

Каждая строка — JSON. `null` измерения означает, что оно не обновилось
в этом кадре или было отклонено; причины указаны в `notes`. В отличие
от прошивки скрипт не использует кеш предыдущих измерений за 2 секунды.
Расчёты выполняются с float, а прошивка — с целочисленным округлением.
PF delta — сырая модульная разность, не доказательство переполнения и
не проверенный прирост энергии. Пожизненную энергию скрипт не вычисляет.
Без сети показания/статусы могут отличаться от рабочего режима.

Ctrl+C завершает захват с итоговой статистикой. Готовый raw-файл не
перезаписывается: при следующем захвате выбрать новое имя. Код выхода
0 — есть корректные кадры, 2 — нет, 1 — ошибка ввода/вывода.

Декодировать ранее сохранённый поток (pyserial не нужен):

```sh
python3 smart_plug/tools/hlw8032_monitor.py --input /tmp/hlw_capture_01.bin
```

При использовании `--input` параметр `--raw` не применяется.
Для диагностики передать файл `.bin` и `.jsonl`. Скрипт пока не проверен
с физическим USB-UART и этой платой.
